# IRCTC Microservices

A production-inspired railway reservation system built with a microservices architecture.

## Tech Stack

- Node.js
- Express
- TypeScript
- PostgreSQL
- Redis
- RabbitMQ
- Docker
- GitHub Actions
- AWS

## Architecture

- API Gateway
- Auth Service
- Train Service
- Search Service
- Booking Service
- Payment Service
- Notification Service
