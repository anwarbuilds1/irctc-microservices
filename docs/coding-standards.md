# Coding Standards

## Language

- TypeScript
- Strict mode enabled

## Formatting

- Prettier
- ESLint

## Naming

Folders: kebab-case

Files: kebab-case

Classes: PascalCase

Interfaces:

IUser ❌

User ✅

Variables:

camelCase

Constants:

UPPER_SNAKE_CASE

Enums:

PascalCase

## Commits

Use Conventional Commits.

Examples:

feat:
fix:
refactor:
test:
docs:
chore:

## Error Handling

Use custom error classes.

Never throw plain strings.

## Logging

Use structured logging.

Never use console.log in production code.
